# Roadmap

## MVP

Event/candidate/panel management, invite-based mobile scoring, secure validation, live-derived results, audit log, and Excel export.

## Future upgrades

- Microsoft 365 OneDrive/SharePoint sync through Microsoft Graph
- SMS/email invitations and reminders
- Judge accounts and SSO
- Branded PDF reports
- Analytics, calibration, and audit-report dashboards
- Postgres, background jobs, webhooks, and real-time subscriptions for multi-site deployment
